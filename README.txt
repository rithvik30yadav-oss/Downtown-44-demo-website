DOWNTOWN 44 MULTI-PAGE REDESIGN CONCEPT — EMBER WEB

This is an independent, unofficial design concept. It is not commissioned by, endorsed by, or affiliated with Downtown 44. Do not present it as an official website.

PAGES (separate HTML files):
- index.html — Home
- brands.html — Brand directory with working category filters
- experiences.html — Dining, retail and family experiences
- destination.html — Property highlights
- visit.html — Public location/contact details and official links

ASSETS:
- assets/css/style.css
- assets/js/main.js

PREVIEW:
Keep the assets folder beside the HTML files. Open index.html in a modern browser. Internet is needed for remote Unsplash photos and Google Fonts.

FUNCTIONALITY:
Multi-page navigation, mobile navigation, scroll reveal animations, reduced-motion support, brand filters, external official links. No real booking, payment, enquiry submission, or data collection is implemented.

FACTUAL NOTES:
Brand names and property highlights are adapted from publicly available Downtown 44 pages. Availability and facilities can change; confirm before presenting. Contact/address shown are from their public contact page. Images are remote Unsplash images; replace or license appropriately before commercial use. The design uses no official logos and should remain clearly marked as an unofficial concept.

Before contacting the client, involve a parent/guardian and do not imply endorsement or approval.
